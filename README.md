## 📦 What Is InkDoc?

InkDoc is a free, open-source desktop application that converts various document formats into Markdown—the simple text format that AI tools, developers, and content creators love. Whether you have PDFs, Word documents, HTML files, or scanned images, InkDoc processes them all into structured, readable Markdown.

**Why Markdown?** Markdown is a universal text format that AI systems, note-taking apps, and websites understand natively. It's lightweight, easy to edit, and perfect for feeding into language models or knowledge bases.

## 🔧 Troubleshooting

### "The app won't open on Windows"
- Make sure you downloaded the correct file (`.exe` for Windows)
- Check that your antivirus isn't blocking the application
- Right-click the installer and select "Run as administrator"

### "My PDF has garbled text"
- Enable OCR mode from the settings menu
- Ensure your PDF isn't password-protected
- Try converting the file at a higher DPI setting

### "The app is slow on large files"
- Close other applications to free up memory
- Break very large documents (100+ pages) into smaller sections
- Update to the latest version for performance improvements

### "Where are my converted files?"
- By default, converted files save to the same folder as the original document
- Check your Downloads folder if using batch conversion
- You can change the default location in Settings
